wagmi_tracker Agent API

Pay-per-call wallet checks and coin scans for AI agents, using x402 on Solana devnet. No accounts, no API keys, no subscription. The website itself stays free and never asks you to connect a wallet.

How a paid call works

1
Ask. GET /api/x402/wallet-check?chain=sol&address=… returns 402 Payment Required with a PAYMENT-REQUIRED header: price, devnet USDC mint, payTo, the fee sponsor and a signed one-time quote (memo).
2
Pay. The agent signs a Solana transaction with its own key: one SPL TransferChecked to payTo plus a Memo with the quote. The sponsor pays the network fee, so the agent needs only USDC.
3
Verify & settle. The agent retries with PAYMENT-SIGNATURE. The server checks amount, mint, recipient, quote, expiry and replay, then the facilitator settles on Solana and the server re-reads the confirmed transaction from the chain.
4
Deliver. 200 with the JSON result and a PAYMENT-RESPONSE header carrying the Solana tx signature (or 202 + a free poll URL while a fresh scan runs).

Try it with the demo agent

python3 agent_demo.py --server http://localhost:8787 --chain sol --address <wallet>
python3 agent_demo.py ... --fail wrong-amount   # or wrong-mint, wrong-recipient, replay, expired, tampered-quote, garbage, no-funds

Failed payments get a clear reason, never the data

wrong_amountwrong_assetwrong_recipientreplayed_paymentpayment_expiredinvalid_quotequote_resource_mismatchmemo_mismatchinvalid_signatureinsufficient_fundssettlement_unconfirmedinvalid_payload (400)

Bad addresses are refused with 400 before any quote, so nobody pays for invalid input. An unconfirmed payment can be retried with the same header and is never charged twice.
